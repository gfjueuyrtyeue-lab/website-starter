# เว็บไซต์ตัวอย่าง

เว็บสแตติกแบบ HTML/CSS ที่เตรียมไว้สำหรับปรับแต่งต่อใน Antigravity และเผยแพร่ด้วย GitHub Pages

## แก้ไขเว็บ

แก้ไฟล์ `index.html` แล้ว push ไปที่ branch `main` เพื่อเริ่ม workflow เผยแพร่

## เผยแพร่

ไฟล์ workflow อยู่ที่ `.github/workflows/pages.yml` เมื่อรีโพซิทอรีเป็น public และเปิดใช้ GitHub Pages แบบ GitHub Actions แล้ว การ push ไปที่ `main` จะเผยแพร่เว็บให้อัตโนมัติ
